# Data Engineering --- 100 Days

Programa prático de Engenharia de Dados.

## Objetivo

Até dezembro de 2026, desenvolver capacidade de projetar, implementar,
testar e operar pipelines, Data Warehouses, Data Lakes e Lakehouses com
foco em fundamentos, I/O, observabilidade e custo.

## Método

**Teoria → Código → Revisão e Consolidação.**

A IA atua como tutora e revisora, não como autora primária do código.

## Início de sessão

1.  Leia `CONTEXT.md`.
2.  Leia `CURRENT_STATE.md`.
3.  Consulte `ROADMAP.md`.
4.  Abra o ciclo atual.
5.  Ao terminar, atualize estado e progresso.
