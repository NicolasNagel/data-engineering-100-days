# Engenharia de Custos

Custo total = compute + storage + requests + network + licenças +
operação + complexidade.

Para cada arquitetura registrar volume, retenção, frequência,
CPU/memória, storage, requests, transferência, serviços sempre ligados,
custo mensal e custo com 10x volume.

Princípio: escolher a solução mais simples que cumpra SLA,
confiabilidade e escala.
