# Catálogo de Conceitos

Para cada conceito registrar: - problema que resolve; - definição com
minhas palavras; - exemplo; - quando usar; - quando não usar; -
trade-offs; - como reconhecer em outro problema.

Fila inicial: I/O, idempotência, watermark, CDC, SCD, schema evolution,
partitioning, predicate pushdown, column pruning, OLTP/OLAP, dimensional
modeling, orchestration, lineage e observability.
